2D Pixel Mecha Shooter

Introduction

This project is a 2D top-down shooter game engine built from scratch using C++. The goal was to understand the low-level architecture of game engines, avoiding the use of pre-made engines like Unity or Unreal. It features a custom ECS-like component system, a finite state machine for AI, and a grid-based physics system.

Hero Character & Animation

The player character features a robust animation state machine. Animations are handled via a sprite sheet system that synchronizes with player input and movement states (Idle, Run, Shoot).

NPC Logic & Settings

The game features distinct enemy types, each with unique behaviors driven by a Finite State Machine (FSM). The AI evaluates player distance and line-of-sight to transition between Idle, Chase, and Attack states.

Data-Driven Map System

The game supports loading level data from external JSON/XML files. This data-driven approach allows for rapid iteration of level design (Tilemaps, Enemy Spawns, Collision Layers) without recompiling the C++ code. The map rendering uses a Tilemap system optimized for batch rendering.
