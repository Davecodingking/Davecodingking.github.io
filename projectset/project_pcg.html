PCG City Generator

Project Overview

Developed a Procedural Content Generation (PCG) city generator based on Houdini for my graduation project. This tool allows users to generate complex city layouts with custom zoning, road networks, and building placements efficiently.

The system supports visualized parameter panels within Unreal Engine 5 via Houdini Engine, enabling real-time adjustments and iterations.

Key Features

  • Custom City Zoning Algorithms
  • Procedural Road Network Generation
  • Visualized Parameter Panel in UE5
  • External Asset Import Support

Technologies

Houdini Unreal Engine 5 Python VEX
